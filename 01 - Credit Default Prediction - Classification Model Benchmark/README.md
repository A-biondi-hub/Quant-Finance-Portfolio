# Credit Default Prediction: A Classification Model Benchmark

Benchmark of 14 classification models (including variants) for predicting whether a credit applicant will default, built in R on a dataset of 6,000 credit requests. All models share the same cleaning, the same stratified 70/30 train/test split and the same evaluation metrics, so the results are directly comparable.

**Full report (code, output, plots and commentary): [`credit_default_benchmark.md`](credit_default_benchmark.md)**

## Highlights

- **Heavy class imbalance**: only 6.7% of the applicants default, so a model that always predicts "no default" already reaches 93.3% accuracy. The benchmark therefore looks at Recall, F1 and AUC, not only at accuracy.
- **Best ranking model: LDA (AUC 0.843)**, closely followed by QDA, Naive Bayes, logistic regression, boosting and the neural networks (AUC 0.83-0.84), even though the LDA assumptions are only partly satisfied.
- **Best ensemble: boosting (AUC 0.832)**, ahead of random forest (0.807) and bagging (0.803).
- **A pruned classification tree with 3 splits** has the highest recall (0.727) but a low precision: the choice of the model depends on the cost of a missed default compared with the cost of a false alarm.
- At the standard 0.5 threshold most models detect only a minority of the defaulters, even when their AUC is good.

## What the project covers

- Data cleaning (implausible values, winsorising of the upper tail) and exploratory analysis
- Stratified train/test split and scaling with training-set statistics
- Logistic regression (with interpretation of the odds ratios), LDA, QDA, Naive Bayes, KNN with cross-validated K
- Classification trees with pruning, a regression tree, bagging, random forest, boosting with cross-validated number of trees
- Three neural networks (Keras/TensorFlow, `nnet`, `neuralnet`)
- Final comparison with Accuracy, Precision, Recall, F1 and AUC

## How to run

1. Put `credit.csv` in the `data/` folder (see [`data/README.md`](data/README.md)).
2. Install the packages:

   ```r
   install.packages(c("MASS", "class", "e1071", "rpart", "rpart.plot", "randomForest",
                      "gbm", "nnet", "neuralnet", "NeuralNetTools", "pROC", "corrplot",
                      "caret", "dplyr", "rmarkdown"))
   ```

3. Optional, only for the Keras network: `install.packages(c("keras3", "tensorflow", "reticulate"))` followed by `keras3::install_keras()`. Without TensorFlow, set `run_keras <- FALSE` in the first chunk of the `.Rmd` and the Keras section is skipped.
4. From this folder, render the report:

   ```r
   rmarkdown::render("credit_default_benchmark.Rmd")
   ```

The analysis uses `set.seed(383)`; models with a random component may differ in the last decimals on other machines or package versions.
